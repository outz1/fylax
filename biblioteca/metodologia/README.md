# Biblioteca / Metodologia

Métodos que valem para qualquer instância deste tipo de projeto. **Sem números locais**: número vai para `ESTADO.md`, resultado bruto para `evidencias/`.

Um arquivo por tema (`<tema>.md`), no formato:

```
# <tema>
Quando usar: ...
Passos: 1. ... 2. ...
Armadilhas: ...
Origem: <data> | <sessão/commit que gerou a lição>
```
